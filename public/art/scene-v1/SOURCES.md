# Scene v1 asset sources

The two original ship illustrations were generated with the OpenAI built-in image_gen tool on 2026-10-15 for this project. Original generated files are retained; the PNG files here are unchanged copies preserving true alpha transparency.

- `shuttle.png`: silver-white transport shuttle; 1774 × 887 RGBA; rear engines on the left, nose to the right.
- `cruiser.png`: silver-white patrol cruiser; 2048 × 768 RGBA; rear engines on the left, bow to the right.

Both use blue-gray metal, restrained warm-gold details and hand-painted / cel-shaded environmental concept-art styling. Neither includes text, insignia, characters or a baked-in scene background.

Full generation prompts and local original source paths are retained in `output/scene-v1/image-sources.json`. The separate TAPNOW sample is a single authorized 5-second draft cloud-motion render based on the existing observatory painting; it is not part of these ship sprites.

`cloud-bank.png` is an original 1536 × 1024 transparent cloud-sea painting generated with the built-in image_gen tool on 2026-10-15, copied unchanged with true alpha. It is rendered as two independently moving cloud-sea layers, softly revealed below the fixed skyline and clipped inside the window. The full prompt and original source path are retained in `output/scene-v1/cloud-sources.json`. No additional TAPNOW render was made for this correction.
