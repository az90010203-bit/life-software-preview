# 人生 0.1.0：iPhone 使用说明

网址：https://az90010203-bit.github.io/life-software-preview/

## 添加到主屏幕

1. 在 iPhone 的 Safari 中打开上面的网址。
2. 点分享按钮，选择“添加到主屏幕”。
3. 名称保留“人生”；若显示“作为网页 App 打开”，保持开启，再点“添加”。
4. 以后从“人生”图标进入，底栏切换今天、随手记和月历；“记一下”可直接开始输入。

Safari 标签页与主屏幕应用应当作两个独立入口，分别登录同一个私人账号。不要假设安装会复制 Safari 的草稿、记录或登录状态。

## 查看保存和同步状态

手机顶栏会显示状态；点右上角设置可以查看详情与手动同步。

- **仅保存在此设备**：云端尚未配置，当前记录没有上传，不能跨设备取回。
- **N 项待同步**：记录已经进入设备数据库和待上传队列，重新联网后自动重试。
- **正在同步／已同步**：正在处理队列，或最近一次同步已经完成。
- **N 项待确认**：两个设备修改了同一内容，请在设置中查看双方版本，选择采用云端版本或保留本地副本。
- **离线模式**：暂时无法连接云端，可继续使用设备上的记录；输入区的草稿状态单独显示。

本版本已配置私人云端，只支持预置的私人邮箱和密码，不提供公开注册。在设置中的“你的私人空间”登录；使用创建应用账号时填写的邮箱和 User Password。首次登录会显示本机已有记录数量，确认后再绑定并上传。草稿、场景和桌面布局保存在各自设备，不通过云端同步。

应用打开、恢复前台、保存和网络恢复时触发同步，前台也会定时检查。iOS 挂起应用后不会持续同步。

## 离线、更新和备份

联网打开并在设置看到“离线入口已准备好”后，断网仍可进入。大型背景素材按需加载，离线时部分装饰可能缺失。首次离线打开一个从未加载过的入口，需要先恢复网络。

有新版本时，设置中的安装区显示更新提示。选择“保存并更新”后，应用先等待本机写入成功，再重新打开；保存失败会保留页面和输入，稍后重试即可。待上传队列不会因更新而清空。

设置中的“找回本机草稿”可以把旧会话或其他窗口留下的输入恢复成随手记，保留原窗口的草稿。同一版本重复恢复不会创建多个副本。

插件的更多菜单可以导出 JSON，包含记录、草稿和待同步状态。备份包含私人内容，请保存在自己的文件中。删除浏览器网站数据、卸载入口或更换设备前，先确认已同步并导出备份。
